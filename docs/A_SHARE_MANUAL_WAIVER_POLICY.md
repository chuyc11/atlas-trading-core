# A Share Manual Waiver Policy

v0.8.14 does not automatically approve waivers.

Manual waiver artifacts are schema and workflow support only:

- default decision status: `not_requested`
- manual waiver approval recorded: false
- auto waiver allowed: false
- waiver changes gate decision: false
- approved for trading: false

Waiver cannot override broker/order/boundary violations, protected path modifications, or trading/investment outputs.
