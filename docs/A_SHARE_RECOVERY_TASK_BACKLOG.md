# A Share Recovery Task Backlog

The v0.8.15 recovery backlog converts v0.8.14 quality exceptions into non-trading owner-readiness quality tasks.

## Backlog Rules

- tasks are generated from exception evidence
- tasks are planned by default
- tasks require evidence before completion
- wait-for-history items are separated from actionable developer work
- forbidden categories such as broker, real account, real order, and live trading enablement are rejected
