# A Share Build Output Monitoring Refresh

v0.8.10 refreshes monitoring context from the build-output dashboard.

It carries build-output warnings, alert counts, known non-blocking context, and external-notification-disabled status into the build-output ops refresh package.

This monitoring refresh is local and research-only. It does not send external notifications, does not refresh data, does not rerun monitoring, does not connect broker, does not place orders, and does not treat alerts as trade instructions.
