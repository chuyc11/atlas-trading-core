# A-Share Validate Dashboard vs Build Dashboard

v0.8.9 compares the earlier validate-source owner dashboard with the new build-output owner dashboard.

Expected difference:

- validate dashboard source mode: `validate_existing_artifacts`
- build-output dashboard source mode: `build_from_existing_data`

Unexpected differences are blocking when they indicate missing required cards, business output drift, protected path drift, source trace drift, or boundary drift.

The comparison is an owner-facing evidence check only. It is not a trading signal and does not authorize any order workflow.
