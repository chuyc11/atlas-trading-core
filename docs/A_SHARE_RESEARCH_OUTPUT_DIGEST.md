# A-Share Research Output Digest

The v0.8.11 research output digest is generated at:

- `data/equity_owner_daily_pack/daily/YYYY-MM-DD/research_output_digest.json`
- `outputs/equity_owner_daily_pack/daily/YYYY-MM-DD/A_SHARE_RESEARCH_OUTPUT_DIGEST.md`

It summarizes the build-output research state from existing artifacts:

- `source_workflow_mode=build_from_existing_data`
- build-output research status
- candidate summary availability
- virtual portfolio summary availability
- benchmark summary availability
- performance summary availability
- attribution summary availability
- repeatability status
- business output drift count
- warning context
- artifact links

The digest is research-only and virtual-only. It does not regenerate scores, candidates, or portfolios. It does not generate buy/sell signals, order previews, broker instructions, real orders, profit claims, or live readiness.
