# Plan Alignment and MVP Gaps

v0.5.8.1 adds plan alignment and MVP gap audit for the current research-only trading-core project.

Plan alignment is an audit, not day 1 authorization. This workflow does not start forward dry-run, does not call `run-daily`, and does not write the main orders/trades/portfolio/accounts ledger.

## Commands

```powershell
python -m trading_core.cli plan-checklist
python -m trading_core.cli mvp-requirement-map
python -m trading_core.cli artifact-coverage-scanner
python -m trading_core.cli classify-mvp-gaps
python -m trading_core.cli classify-day1-blockers
python -m trading_core.cli next-work-register
python -m trading_core.cli audit-plan-alignment
```

## Boundaries

- This does not start forward dry-run.
- `run-daily` is not called.
- Main ledger is not written.
- Historical replay is not forward validation.
- Historical performance is not strategy effectiveness proof.
- ML shadow is research only and is not day-1 authorization.
- LLM is not used for trading decision.
- RL is not used.
- Automatic promotion is not triggered.
- Live trading readiness is not certified.
