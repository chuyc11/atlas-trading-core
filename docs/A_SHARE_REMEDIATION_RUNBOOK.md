# A Share Remediation Runbook

The owner remediation runbook answers safe operational questions:

- which warning, blocker, or alert is present
- which upstream artifact should be inspected first
- whether the issue is data, provider, schema, freshness, coverage, workflow, dashboard, monitoring, boundary, known non-blocking, insufficient-history, or unknown
- whether manual review is required
- which safe validation commands may be reviewed by a human

The runbook is not an investment recommendation. It does not authorize trades, connect broker, place orders, generate buy/sell signals, refresh data, rerun research workflow, call old run-daily, or execute official forward dry-run day2.
